# Eye of Chignecto

Overview:
The Chignecto Resilience Monitor is an interactive geospatial application designed to track flood risks and major storms across the Chignecto region using satellite radar data. By combining satellite radar imagery from Canada’s RADARSAT Constellation Mission (RCM) and Sentinel-1, our processing pipeline using Python automatically detects and maps flooded areas across a consistent 50-meter grid. Using NRCan historical flood records and OpenStreetMap basemaps via Leaflet, this tool provides an educational overview of how major events such as storms and floods impact the Chignecto Isthmus.
